# Практическая работа «Парсер страницы»

Стартовый код практической работы 6.1.

## Как начать

1. Откройте файл `index.html` в браузере — это страница товара, с которой парсер собирает данные.
2. Откройте консоль браузера: там результат проверки.
3. Пишите код в файле `parser.js`: функции `getProduct()`, `getSuggested()` и `getReviews()`.
   Функция `getMeta()` уже готова — используйте её как образец.
4. После каждого изменения обновляйте страницу и смотрите, какие разделы проверка уже приняла.

Остальные файлы менять не нужно: `main.js` оживляет страницу, `tests.js` проверяет работу.
